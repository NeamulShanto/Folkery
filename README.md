# Folkery

A community collection of folk stories from around the world. Folkery aims to preserve and share the tales people pass along—along with the cultural context and sources that help readers understand them.

## Contributing a story

Stories, translations, and helpful corrections are welcome. When adding a story:

- Use a clear title and write in Markdown.
- Include the story's region or cultural tradition when known.
- Credit the storyteller, translator, or source when available.
- Note whether the story is a retelling or translation, and respect applicable copyright and permissions.
- Avoid presenting one version as the only or definitive version of a traditional tale.

A useful starting format:

```markdown
# Story title

- **Tradition/region:**
- **Language:**
- **Told or translated by:**
- **Source:**

Story text goes here.

## Notes

Optional context about the story, its variants, or the source.
```

Please keep contributions respectful and make it clear when details are uncertain. If the project adopts a particular directory or metadata format, follow the existing conventions.
